`example-selfie.jpg` is a resized JPEG copy of the TensorFlow.js face-detection test portrait, reused from this project's test fixtures for the explicitly labeled example journey.

Source: https://github.com/tensorflow/tfjs-models/blob/master/face-detection/test_data/portrait.jpg
Source project license (Apache 2.0): https://github.com/tensorflow/tfjs-models/blob/master/LICENSE

This sample does not represent a Jala user. User-selected selfies stay in memory and never enter browser storage in the sample journey.
